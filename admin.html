Token kahan se milega? (aasan steps)
  1. GitHub kholein, apni photo dabayein, phir Settings.
  2. Sab se neeche Developer settings.
  3. Personal access tokens → Tokens (classic).
  4. Generate new token (classic), naam likhein, sirf repo tick karein.
  5. Neeche Generate token dabayein, token copy kar ke yahan paste karein.

📁 Folders (repo mein)

Har product, category, service aur banner ka apna alag folder banta hai.

Madad (aasan steps)

  1. Product add karna: Products → + Add → naam, qeemat, kitne piece, photo → Save.
  2. Piece bik gaya: Product ke saamne "Sold 1" dabayein, stock khud kam ho jayega.
  3. Category / Service: Categories ya Services tab mein naam likh kar Save karein. Edit dabane se naam ya tafseel badal sakte hain.
  4. Banner: Banners mein photo chunein aur Upload dabayein.
  5. Dikhne mein waqt: Website par 1-2 minute, app mein 5 minute tak.
  6. WhatsApp number Settings mein zaroor likhein, warna customer order nahi bhej sakega.
